AI agents are becoming increasingly complex. They call models, tools, APIs, MCP servers, and other agents, often across long-running workflows.

**Blazo gives developers visibility into those executions.**

Trace agent runs, inspect tool calls and LLM calls, view logs and errors, track latency and token usage, and understand where an agent gets stuck.

```bash
blazo watch
```

Blazo is built **open-source and local-first**, with TypeScript, Bun, OpenTelemetry, and MCP at its core.

### What we're building

* 🔥 Agent execution traces
* 📋 Structured logs
* 🛠 Tool & MCP visibility
* ⚡ Live run monitoring
* 🐛 Error tracking
* 💰 Token & cost tracking
* 🔍 Stuck-agent detection
